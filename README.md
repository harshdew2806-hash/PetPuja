# PetPuja

# 🚀 React Native Mobile Application

A modern and scalable **React Native mobile application** built with a clean component-based architecture and structured navigation. The project is designed with maintainability, smooth user experience, and future scalability in mind.

## ✨ Overview

This project demonstrates the development of a cross-platform mobile application using **React Native** and **TypeScript**. It follows a modular structure where navigation and reusable UI components are separated into dedicated directories, making the application easier to maintain and extend.

The application uses **React Navigation** for screen-to-screen navigation and **React Native Gesture Handler** to provide a smooth and responsive interaction experience.

## 🛠️ Tech Stack

* **React Native** – Cross-platform mobile application development
* **TypeScript** – Type-safe and maintainable code
* **React Navigation** – Application navigation and screen management
* **React Native Gesture Handler** – Smooth gesture-based interactions
* **Component-Based Architecture** – Reusable and maintainable UI components

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd YOUR_PROJECT_NAME
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

You can then run the application on an Android emulator, iOS simulator, or a connected mobile device depending on your development environment.
